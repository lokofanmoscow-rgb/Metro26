# Метро 26 — симулятор машиниста Московского метро

Браузерная 3D-игра: вы — машинист поезда Московского метро. Вид из кабины с обзором во все стороны,
станции, построенные по описаниям оформления из Википедии, пассажиры, которые выходят и садятся в вагоны,
схема метро с вашим положением и сохранения.

## Как играть

Откройте файл **`dist/index.html`** в браузере (Chrome, Edge, Firefox, Safari) — сервер не нужен,
вся игра собрана в один файл.

1. В меню выберите линию (пока доступны **Сокольническая** и **Калужско-Рижская**), направление и поезд.
2. На первой станции идёт посадка: закройте двери и трогайтесь.
3. Остановите поезд головой у отметки «СТОП» в конце платформы, откройте двери, дождитесь посадки,
   закройте двери — и дальше по линии. На конечной можно сразу поехать обратным рейсом.

### Управление

| Клавиша | Действие |
|---|---|
| **W** / ↑ | ход (держать) |
| **S** / ↓ | тормоз (держать) |
| **Пробел** | открыть / закрыть двери |
| мышь (зажать и вести) | осмотреться по сторонам, колесо — зум |
| **C** | вид снаружи на станции (поезд и посадка пассажиров) |
| **M** | схема метро с положением поезда |
| **Esc** | пауза: сохранение, загрузка, настройки |
| **H** | скрыть / показать приборы |

На телефоне и планшете те же действия — экранными кнопками, обзор — пальцем.

### Очки

- точная остановка у отметки: до 0,5 м — 100 очков, до 1,5 м — 75, до 3 м — 50, до 6 м — 25;
- превышение ограничения АРС включает автоторможение и снимает очки;
- проезд станции без остановки — −150, закрытие дверей во время посадки — −15.

## Что есть в игре

- **Схема метро** повторяет карту из присланного MHT-файла (moscowmap.ru): все линии метро, пересадки
  и строящиеся участки. МЦК и все линии МЦД исключены.
- **Линии.** Сокольническая (27 станций, от «Бульвара Рокоссовского» до «Потапово») и Калужско-Рижская
  (24 станции, от «Медведково» до «Новоясеневской»). Длины перегонов посчитаны по координатам станций;
  в меню можно включить сокращённые перегоны.
- **Станции** генерируются по описаниям из Википедии: тип конструкции (колонная «сороконожка»,
  пилонная трёхсводчатая, односводчатая, наземная крытая, станция на метромосту), цвет и рисунок облицовки
  путевых стен, колонн/пилонов, пола и потолка, светильники, название на путевой стене, указатели,
  часы-интервальник, выходной светофор. Например: красный мрамор и арки «Красных Ворот», раскрывающиеся
  капители «Кропоткинской», стеклянные стены «Воробьёвых гор» над Москвой-рекой, «пирамидки» «Медведково»,
  мозаичный фриз «Свиблово».
- **Открытые участки:** Лужнецкий метромост с видом на реку, Лужники и МГУ; наземный участок с крытыми
  станциями «Филатов Луг» и «Прокшино».
- **Три поезда:** 81-717/714 «Номерной», 81-775/776 «Москва-2020», 81-740/741 «Русич» (сочленённый) —
  со своей ливреей, лобовой маской, маршрутным указателем и кабиной (аналоговый скоростемер с лампами АРС
  у «Номерного», экраны у новых поездов).
- **Пассажиры** ждут на платформе, выходят из вагонов и садятся в двери; встречные поезда.
- **Звук:** тяговые двигатели, стук колёс на стыках, тормоза, двери, сигнал АРС и голосовые объявления
  («Осторожно, двери закрываются. Следующая станция — …»), если браузер поддерживает русскую речь.
- **Сохранения:** 5 слотов и автосохранение на каждой станции (в браузере, `localStorage`).

## Разработка

```bash
npm install
npm run build      # собирает dist/index.html
```

Структура:

```
src/
  data/scheme.js     схема метро, извлечённая из MHT (станции, линии, перегоны, пересадки)
  data/lines.js      игровые линии: порядок станций, перегоны, оформление каждой станции, поезда
  engine/route.js    трасса: план с кривыми, продольный профиль, зоны, ограничения АРС
  engine/station.js  генератор станций по описанию оформления
  engine/tunnel.js   тоннели (тюбинги и прямоугольные), путь, контактный рельс
  engine/outdoor.js  метромост, наземный участок, небо
  engine/train.js    модели поездов и кабины
  engine/people.js   пассажиры
  engine/audio.js    синтез звуков и объявления
  game.js            физика поезда, станции, камеры, подгрузка мира
  ui/map.js          схема метро
  main.js            меню, HUD, сохранения
```

Чтобы добавить новую линию, опишите её станции в `src/data/lines.js` (порядок, `sid` станции на схеме,
расстояние до следующей станции и оформление) и добавьте её id в `PLAYABLE`.

Сторонние библиотеки: [three.js](https://threejs.org) (MIT).
