# Данные OpenStreetMap

Окружение открытых участков (здания, дороги, вода, парки, оси путей) построено по данным
© участники OpenStreetMap, лицензия ODbL 1.0 — https://www.openstreetmap.org/copyright

Данные загружены скриптом `tools/osmdl.py` (небольшие квадраты через API OpenStreetMap) и
обработаны `tools/osmbuild.py` в наземные текстуры, маски воды и описания зданий.
